# Assets

Drop your profile photo in this folder and name it **`profile.jpg`**.

- Recommended: a square head-and-shoulders portrait (e.g. 800 × 800 px), face centered — the site crops it into a circle.
- The site automatically falls back to `profile-placeholder.svg` until `profile.jpg` exists.
- If you use a different file name or format, update the `src` in `index.html` (search for `profile.jpg`).
